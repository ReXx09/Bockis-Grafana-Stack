Bocki Grafana AIO

Monitoring auf Unraid, Schritt für Schritt.

Diese Anleitung führt durch die Installation des zentralen AIO-Managers. Der Manager verwaltet InfluxDB, Grafana, Telegraf, Loki und Grafana Alloy als einen gemeinsamen Monitoring-Stack.

Entwicklungsstand: Das AIO-XML und der Manager befinden sich noch in der Entwicklung. Vor dem produktiven Einsatz zuerst ein Backup erstellen und das Image in einer Testinstanz prüfen.

Du brauchst

  • Unraid mit aktiviertem Docker-Dienst
  • eine freie TCP-Verbindung für Port 8800
  • freie Ports 3000, 8086 und UDP 5514
  • ausreichend Speicherplatz für Appdata und Logs

Die fünf Dienste

  • Grafana 11.5.2
  • InfluxDB 2.7
  • Telegraf 1.34
  • Loki 3.4.2
  • Grafana Alloy 1.7.5
1

Arbeitsbereich vorbereiten

Lege in Unraid den Appdata-Ordner an oder verwende den Standardpfad:

/mnt/user/appdata/bocki-grafana-aio

Wenn du einen anderen Pfad verwendest, muss derselbe Hostpfad später bei AIO Appdata, Host Appdata Zugriff und Host Appdata Path eingetragen werden.

Prüfen: Der Ordner ist beschreibbar und hat genügend freien Speicher.
2

AIO-XML importieren

In Unraid:

  1. Docker öffnen.
  2. Add Container auswählen.
  3. Auf Template repositories beziehungsweise XML-Import wechseln.
  4. Die Datei docker/unraid/templates/bocki-grafana-aio.xml aus diesem Projekt verwenden.

Das Template legt nur den Manager-Container an. Die fünf Monitoring-Dienste werden anschließend durch die AIO-WebUI erstellt.

Prüfen: In Unraid ist nur der Container bocki-grafana-aio angelegt.
3

Pfade und Ports setzen

Kontrolliere die Standardwerte:

  • Manager WebUI Port: 8800
  • AIO Appdata: /mnt/user/appdata/bocki-grafana-aio
  • Host Appdata Zugriff: derselbe Hostpfad wie AIO Appdata
  • Grafana Port: 3000
  • InfluxDB Port: 8086
  • Syslog Port: 5514/UDP
  • Docker Socket: /var/run/docker.sock als read-only Mount

Der zusätzliche Hostpfad ist erforderlich, damit die vom Manager erzeugten Konfigurationsdateien für die Fachcontainer sichtbar sind.

4

Image veröffentlichen und prüfen

Das Template verwendet derzeit:

ghcr.io/rexx09/bockis-grafana-aio:0.1.0

Nach jedem Push auf den Branch master baut der Workflow .github/workflows/publish-aio.yml dieses Image automatisch. Unter GitHub bei Packages muss das Paket anschließend auf Public gestellt werden. Erst dann kann Unraid es ohne Anmeldung laden.

Falls der Pull mit denied oder unauthorized endet, existiert das Image noch nicht öffentlich oder das Paket ist privat. Der Fehler No such container ist danach nur eine Folge des fehlgeschlagenen Pulls.

Prüfen: Der Manager-Container startet und zeigt auf Port 8800 eine Webseite.
5

Setup-Assistent ausfüllen

Öffne im Browser:

http://UNRAID-IP:8800

Gib dort mindestens ein:

  • Grafana-Administrator und Passwort
  • InfluxDB-Administrator und Passwort
  • Organisation, zum Beispiel home
  • Bucket, zum Beispiel homelab
  • Retention, zum Beispiel 30d

Der Manager speichert die Konfiguration unter /data/config.json und erzeugt den InfluxDB-Admin-Token automatisch.

Prüfen: Nach dem Speichern erscheint keine Fehlermeldung und die Konfiguration bleibt nach einem Neustart erhalten.
6

Stack installieren

Nach dem Setup startet die WebUI die Stack-Installation. Dabei werden das Docker-Netzwerk bocki-monitoring und diese Container angelegt:

bocki-aio-influxdb
bocki-aio-grafana
bocki-aio-telegraf
bocki-aio-loki
bocki-aio-alloy

Die Konfigurationsdateien und Daten liegen dauerhaft unter deinem AIO-Appdata-Pfad. Bereits vorhandene bocki-aio-*-Container werden bei einem erneuten Installationslauf nicht gelöscht. Nach einer Manager- oder Vorlagenaktualisierung müssen bestehende Fachcontainer einmal in Unraid gestoppt und gelöscht werden; danach die Installation im Manager erneut ausführen.

Prüfen: Alle fünf Dienste erscheinen in der Statusanzeige; InfluxDB, Grafana, Loki und Alloy werden healthy.
7

Grafana öffnen

Rufe Grafana auf:

http://UNRAID-IP:3000

InfluxDB und Loki werden automatisch als Datasources provisioniert. Das Dashboard OPNsense Firewall enthält Pass-/Block-Zähler, Zeitreihen, Loki-Ereignisse und eine Geomap.

Prüfen: Beide Datasources sind erreichbar und das Firewall-Dashboard wird angezeigt.
8

OPNsense verbinden

In OPNsense unter System → Settings → Logging → Remote einen Remote-Syslog-Zielhost eintragen:

  • Zielhost: IP-Adresse deines Unraid-Servers
  • Transport: UDP
  • Port: 5514
  • Facility/Quelle: Firewall beziehungsweise filterlog

Alloy empfängt die Meldungen, strukturiert Aktion, Interface, Richtung und Protokoll und leitet sie an Loki weiter.

Prüfen: In Grafana erscheinen neue filterlog-Ereignisse in der Loki-Tabelle.
9

GeoIP für die Weltkarte

Lege eine rechtmäßig bezogene GeoLite2-City-Datenbank ab unter:

/mnt/user/appdata/bocki-grafana-aio/geoip/GeoLite2-City.mmdb

Der Mount ist optional. Ohne GeoIP funktionieren Logs und Zähler weiter, aber die Länderanreicherung und die Weltkarte bleiben unvollständig.

Prüfen: Die Datenbank stammt aus einer zulässigen Quelle und wird read-only in den Manager eingebunden.
10

Betrieb und Updates

Nutze die AIO-WebUI für Status und Dienstaktionen. Der AIO-Manager selbst wird aus Sicherheitsgründen nicht selbst ersetzt:

  1. Appdata-Backup erstellen.
  2. In Unraid unter Docker beim Container bocki-grafana-aio Force Update ausführen.
  3. Nach dem Neustart die WebUI neu laden.
  4. Danach Dienst-Updates einzeln ausführen.
  5. Grafana, InfluxDB und Loki auf Erreichbarkeit prüfen.

Die Konfiguration bleibt im Appdata-Mount erhalten. Ein produktives Rollback ist noch nicht Bestandteil des aktuellen Entwicklungsstands. Deshalb vorerst das Appdata-Backup behalten.

Raspberry-Pi-Fallback

Für den Raspberry Pi bleibt docker/raspi/docker-compose.yml der alternative Weg. Die zugehörige .env.example kopieren, Geheimnisse ersetzen und die Compose-Datei im Ordner docker/raspi starten.

Fehler melden

Bei Problemen immer den exakten Fehlertext, den betroffenen Schritt und den Status der fünf Container notieren. Keine Passwörter oder Tokens in Logs, Screenshots oder Issues veröffentlichen.
